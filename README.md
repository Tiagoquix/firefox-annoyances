# Project archival
[Firefox version 148](https://www.firefox.com/en-US/firefox/148.0/releasenotes/) added AI controls to the browser, which are acessible by going to `about:preferences#ai`.

From there, you can tick a box that will block all current and future AI additions.

Therefore, there is no point to keep this project alive anymore. (Keeping it just to disable self-promotion is not worth, in my opinion).

The project will be archived. Thanks to you for using it.
